> **Experience Addis Ababa's events like never before.** A high-performance, premium web application designed for discovering, booking, and managing events with a seamless desktop-first experience.

---

## ✨ Key Features

### 🚀 For Users
- **Premium Discovery:** A fluid, glass-morphic interface to browse the latest tech, music, and sports events.
- **Smart Filtering:** Instant search and category-based filtering scaled for high-resolution displays (up to 4K).
- **Secure Ticketing:** Instant booking with Firebase integration and unique QR-code generation for every ticket.
- **Personal Dashboard:** A dedicated "My Tickets" area to manage upcoming and past experiences.
- **Modern Auth:** A sophisticated, split-screen login/signup flow for a smooth onboarding experience.

### 🛠 For Administrators
- **Full Control:** A specialized admin dashboard to create, edit, and delete events in real-time.
- **Capacity Tracking:** Real-time analytics on ticket sales and venue capacity.

---

## 🎨 Design Philosophy

EventSphere was built with a **Premium-First** approach:
- **Fluid Scaling:** Using CSS `clamp()` and media queries optimized for **3072px+ (4K)** displays.
- **Rich Aesthetics:** Modern glass-morphism, vibrant gradients, and smooth micro-animations.
- **Responsive Layouts:** A seamless transition from wide-screen desktops to mobile-responsive views.

## 🚀 Quick Start

### 1. Prerequisites
- Node.js (v18+)
- NPM or Yarn

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/welidemezene/Online-Event-Management.git

# Navigate to the web project
cd EventSphereWeb

# Install dependencies
npm install
```

### 3. Local Development
```bash
npm run dev
```

### 4. Production Build
```bash
npm run build
```
